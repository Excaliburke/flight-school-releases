# Flight School

Downloads and update manifests for Flight School, a Mac app for students in
Canvas courses.

To install, open [the latest release](https://github.com/Excaliburke/flight-school-releases/releases/latest),
download `Flight-School-X.Y.Z.dmg`, open it, and drag Flight School onto
Applications.

The `.zip` and `latest-mac-arm64.json` on each release are read by the app's
**Check for updates**. This repository holds nothing else.
